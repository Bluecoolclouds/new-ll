---
name: Stratus supported languages
description: User-facing language choices and localization boundaries for Stratus.
---

Stratus supports Russian and English only.

**Why:** The user explicitly stated that only English and Russian are possible in this project.

**How to apply:** Keep user-facing copy in Russian and English. For server-generated labels, use the active Stratus language when available and fall back to English; do not expose New API's Chinese default labels in Stratus.
