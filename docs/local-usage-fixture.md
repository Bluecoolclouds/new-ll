# Тестовая статистика локального администратора

Инструмент не запускается автоматически при старте, сборке или развёртывании.
Он поддерживает только существующий `one-api.db` в корне проекта с `.replit`.
При заданных `SQL_DSN`, `LOG_SQL_DSN`, `SQLITE_PATH` или `REPLIT_DEPLOYMENT`
работа запрещена; ссылки на файлы тоже не допускаются. Не переносите инструмент
и локальную базу на production.

Сначала просмотрите цель без записи:

```sh
go run ./cmd/local-usage-fixture
```

Администратор определяется по роли, а не по фиксированному ID. При нескольких
администраторах укажите согласованный `--user-id`. Для записи обязательны ID и
абсолютный путь из предварительного просмотра:

```sh
go run ./cmd/local-usage-fixture --action seed --user-id <ID> --confirm-local "<путь из preview>"
go run ./cmd/local-usage-fixture --action delete --user-id <ID> --confirm-local "<путь из preview>"
```

Заполнение создаёт почасовую историю за 60 суток, включая текущий час, для
четырёх моделей. Набор детерминирован для одного времени запуска, имеет дневные,
недельные колебания и различия между периодами. Расходы — синтетические примеры:
`quota = round(USD × common.QuotaPerUnit)`, модельные токены — сумма входных и
выходных. Это не реальные тарифы провайдеров и не списания с кошелька.

Каждая строка помечена `node_name = __synthetic_admin_usage_v1__`, остальные
служебные измерения пусты/нулевые. Не используйте эту зарезервированную метку
для реального узла. Личные графики группируют данные без `node_name`, поэтому
показывают обычные названия моделей. **Тестовые записи также попадают в общие
административные сводки.**

Повторное заполнение в одной транзакции заменяет только помеченный набор
выбранного пользователя, обновляя его до текущего часа, без удвоения.
Очистка удаляет только строки этого набора и пользователя с соответствующими
служебными измерениями. Другие агрегаты не изменяются. Балансы, журналы,
платежи, ключи и настройки сбора не затрагиваются; вызовов моделей нет.
Инструмент не использует кеш агрегатов и не выполняет миграции.

После заполнения обновите кабинет выбранного администратора. Периоды 24 часа,
7 и 30 дней и соответствующие предыдущие периоды содержат данные.
Один запрос `/api/data/self` по-прежнему ограничен 30 днями: не запрашивайте
все 60 суток одним вызовом. При отключённом сборе существующее предупреждение
о недостоверности сравнения остаётся в силе.

Проверка на временных базах:

```sh
go test ./internal/usagefixture ./cmd/local-usage-fixture
```
