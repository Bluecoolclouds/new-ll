# Как задавать цены моделей для Stratus

## Короткий ответ

Да. Коэффициенты настраиваются в админке New API; отдельного поля для изменения тарифа на странице Stratus нет. Блок «Тарифы Stratus» только читает опубликованные цены и показывает их в токенах кошелька. Реальное списание выполняет New API.

В админке откройте **Системные настройки → Биллинг → Model Pricing → Model prices**. Выберите модель, измените тариф в визуальном редакторе или JSON и нажмите **Save model prices**. Для коэффициентов пользовательских групп используйте отдельно **Group Pricing → Group ratios**. Вкладка **Upstream price sync** может помочь заполнить начальные значения, но после синхронизации проверьте соответствие моделей и актуальные цены поставщика.

## Что означают поля

- **Model ratio** — базовая ставка текстовой модели для входных токенов.
- **Completion ratio** — во сколько раз ставка выходных токенов выше базовой. Цена выхода равна цене входа, умноженной на этот коэффициент.
- **Group ratio** — дополнительный множитель для группы пользователя. Он применяется поверх тарифа модели.
- **Cache / Image / Audio ratios** — отдельные ставки для соответствующих типов использования. Их нельзя считать обычным текстовым коэффициентом.
- **Model price** — фиксированная цена вызова для тарифа «за запрос».
- **Tiered expression** — динамический тариф. Его условия рассчитывает сервер, а не Stratus.

При обычном текстовом расчёте New API списывает внутреннюю квоту по числу токенов и настройкам модели/группы. При стандартных **500 000 единиц квоты за 1 USD** редактор New API показывает приблизительно:

```text
Цена входа за 1 млн токенов, USD = Model ratio × 2 × Group ratio
Цена выхода за 1 млн токенов, USD = цена входа × Completion ratio
```

Если единиц квоты за доллар в вашей установке другое число, пересчитайте ставки по текущему значению `quota_per_unit`, а не полагайтесь на пример с 500 000.

## Как получить коэффициент Stratus

Для Stratus один миллион токенов кошелька соответствует **0,13 USD** (11,57 ₽ при курсе 89 ₽/USD). Страница коэффициентов переводит цену New API в расход токенов кошелька:

```text
× входа = Model ratio × Group ratio × 1 000 000
         / (quota_per_unit × 0,13)
× выхода = × входа × Completion ratio
```

При `quota_per_unit = 500 000` это упрощается:

```text
× входа ≈ Model ratio × Group ratio × 15,3846
```

Например, при `Model ratio = 0,39`, `Completion ratio = 1` и `Group ratio = 1` получится примерно **×6** и для входа, и для выхода. Это пример расчёта, не рекомендация автоматически выставить такой тариф всем моделям.

Если хотите одинаковый коэффициент для входных и выходных текстовых токенов, задайте `Completion ratio = 1`. Но сначала сравните цены поставщика: если выход у него дороже, одинаковый коэффициент может не покрыть фактические расходы. При разных ставках Stratus показывает диапазон, а не притворяется, что у модели один тариф.

## Как выставлять цену от стоимости поставщика

1. Возьмите актуальные цены поставщика **за 1 млн токенов**, отдельно для входа и выхода. Для кэша, изображений и аудио используйте соответствующие ставки.
2. Выберите цену продажи. Например, для наценки 15% умножьте цену поставщика на `1,15`.
3. При стандартных 500 000 единиц квоты за доллар задайте:

   ```text
   Model ratio = целевая цена входа, USD за 1 млн / 2
   Completion ratio = целевая цена выхода / целевая цена входа
   ```

   Пример: вход стоит $1,25/млн, выход — $10/млн, без дополнительной наценки:

   ```text
   Model ratio = 1,25 / 2 = 0,625
   Completion ratio = 10 / 1,25 = 8
   ```

   Групповой множитель задаётся отдельно. При `Group ratio = 1` расчёт не получает дополнительного повышения или скидки от группы.
4. Сохраните тариф и проверьте его в «Тарифах Stratus». Затем проверьте одно контролируемое использование и сравните фактическое списание с ожидаемым.

## Важные отличия

- История New API (`quota`) показывает **сколько квоты было списано по действовавшему тогда тарифу**. Это не счёт поставщика и не основание пересчитывать старые запросы по сегодняшним ценам. Изменение тарифов влияет на будущие запросы.
- Публичный каталог Stratus показывает цену «от» с согласованной скидкой 50%. Это только отображение цены: скидка в каталоге **не меняет** фактическое списание токенов.
- Не меняйте `Model ratio` на глаз, чтобы подогнать красивый `×`. Сначала проверьте цену поставщика, выходной коэффициент, группу и специальные ставки. Изменённые настройки сразу влияют на будущие списания пользователей.
- Эта инструкция описывает настройку, но не меняет никакие коэффициенты. Для новых моделей тарифы нужно согласовывать отдельно.
